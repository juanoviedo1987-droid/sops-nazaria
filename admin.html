2. Paso a Paso para Publicar
Caso A: Modificar un manual existente
  1. Elegí el manual en el selector.
  2. Escribí la instrucción y clic en "Generar Vista Previa con IA" (o editalo directo en la hoja).
  3. Clic en "📋 Copiar Código del Manual".
  4. Clic en "↗ Abrir Archivo en GitHub Web", pegá el contenido (`Ctrl+V`) y tocá Commit changes.
Caso B: Crear un manual nuevo
  1. Elegí "➕ [CREAR NUEVO PROCEDIMIENTO]" y completá ID (ej: p11) y Título.
  2. Pegá el borrador y clic en "Generar Vista Previa con IA".
  3. Clic en "📋 Copiar Código del Manual".
  4. Creá el archivo en GitHub en sops/p11.html pegando el código, y agregá la fila al menu.json.
