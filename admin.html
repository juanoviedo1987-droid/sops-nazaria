Manual de Uso y Estándar P-00

Referencia rápida para crear, modificar y publicar

1. ¿Qué herramienta uso y para qué?
🧠 Gemini (HQ / Chat) Para pensar, redactar borradores largos, ordenar ideas de negocio o armar directivas iniciales.
🖥️ Consola Admin (Esta Pantalla) Para maquetar el texto con diseño oficial, previsualizar la hoja real y retocar cualquier párrafo antes de publicar.
☁️ GitHub Web El lugar donde se guardan los archivos finales (dentro de la carpeta sops/ y en la lista menu.json).
📱 App de Sucursales (index.html) La pantalla de consulta limpia que usan las vendedoras y encargadas en cada local.
2. Paso a paso para publicar
Caso A: Modificar un manual que ya existe
  1. Elegí el manual en el selector del panel izquierdo.
  2. Escribí qué querés agregar o cambiar y hacé clic en "Generar Vista Previa con IA" (o editalo directo escribiendo sobre la hoja blanca).
  3. Hacé clic en "📋 Copiar Código del Manual".
  4. Hacé clic en "↗ Abrir Archivo en GitHub Web", pegá el contenido reemplazando lo anterior (Ctrl+V) y tocá Commit changes.
Caso B: Crear un manual nuevo
  1. Elegí "➕ [CREAR NUEVO PROCEDIMIENTO]" y completá el ID (ej: p11) y el Título (ej: P-11 · Nombre Oficial).
  2. Pegá el texto borrador y hacé clic en "Generar Vista Previa con IA".
  3. Hacé clic en "📋 Copiar Código del Manual".
  4. Creá el archivo en GitHub en sops/p11.html pegando el código. Luego agregá la línea con el nuevo botón en menu.json.
3. Reglas de diseño y Emojis oficiales
⚠ Regla de Oro del Código:

Los manuales nunca deben incluir etiquetas como <html>, <head> ni bloques de código (```). Solo se guarda el fragmento interno con el contenido del procedimiento.

Uso obligatorio de Emojis según el tema:
  • 🖥️ Sistemas / Pantallas: Dux Software, consultas en PC y reportes.
  • 📱 Celular / Comunicación: WhatsApp del local, formularios de Google y redes.
  • 💳 Cobros con Tarjeta: Terminales Payway, Nave, Mercado Pago y cupones.
  • 💵 Efectivo: Caja chica, cambio y arqueos de turno.
  • 📦 Mercadería: Control de stock, recepción de cajas, Correo Argentino y auditorías.
  • ✨ Atención al Cliente: Saludo inicial, estética del salón, asesoramiento y fidelización.
  • ⚠ Reglas de Oro: Errores críticos que no se pueden cometer (sección final obligatoria).
